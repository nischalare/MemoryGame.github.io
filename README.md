
# 🧠 Memory Game – Browser Card Matching Game

This project is a **browser-based memory card matching game** built using **HTML, CSS, and JavaScript**.

The objective of the game is to flip cards and match pairs. If two selected cards match, they remain visible. If they do not match, they flip back. The player continues until all card pairs are matched.

This project demonstrates **core front-end development concepts** including DOM manipulation, event handling, and simple game logic.

---

# 🚀 Features

- 🧠 Classic memory card matching gameplay
- 🎮 Interactive card flipping
- 🔄 Cards reset when they do not match
- 🌐 Runs directly in the browser
- ⚡ Lightweight and fast loading

# 🎮 How the Game Works

1. The game loads a grid of face-down cards.
2. The player clicks on a card to flip it.
3. The player selects a second card.
4. If both cards match:
   - They remain visible.
5. If they do not match:
   - They flip back after a short delay.
6. The game ends when all pairs are successfully matched.
